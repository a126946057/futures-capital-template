# Product Idea

## 免費版

- Excel 資金管理模板。
- 基礎回測交易匯入格式。
- 勝率、PF、最大回撤、絕對損益。
- 提領紀錄與帳內鎖定紀錄。
- 免責聲明與使用說明。

## 付費版可能功能

- 多策略模組分開統計。
- 回測與實戰差異對照。
- 保證金歷史變動。
- 固定水位、動態水位、提領後重算口數。
- 大獲利後回吐統計。
- 月損益、季損益與資金曲線圖表。
- Notebook 版分析報告。

## 公開定位

不要把產品定位成「獲利策略」。更適合的定位是：

個人交易者的策略驗證與資金風控系統。

核心價值不是告訴使用者買哪裡，而是幫使用者確認自己的策略是否能承受成本、滑價、回撤、提領與心理壓力。
