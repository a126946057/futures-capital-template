# Publish Checklist

發布到 GitHub 前，確認：

- [ ] README 沒有提到任何私有策略名稱或訊號。
- [ ] Excel 裡只有人工範例資料。
- [ ] 沒有券商截圖、帳戶資金、真實口數。
- [ ] 沒有 API key、token、路徑或個人資料。
- [ ] 免責聲明已保留。
- [ ] LICENSE 已確認。
- [ ] 開源 repo 名稱不要暗示保證獲利。

建議 repo 名稱：

- `futures-capital-template`
- `trading-capital-dashboard`
- `futures-risk-dashboard`

不建議 repo 名稱：

- `profitable-futures-strategy`
- `win-rate-system`
- `auto-profit-trading`
